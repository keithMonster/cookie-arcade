为什么这样分

整体用 Head Start 早期学习与发展框架检查领域遗漏；依游戏设计需要，把认知细分为空间、数量逻辑、因果与解决问题，把创造音乐单独展开。该框架本身明确不作为评估或儿童通过/失败清单。

注意、工作记忆、抑制与规则切换分别记录，参考 Harvard 执行功能资料。数量也不只是认识数字：NAEYC 婴幼儿数学资料包括一一对应、形状空间、测量与模式。

开放创造与角色活动参考 Head Start 假装游戏资料。脑训练研究综述提醒区分特定任务表现与广泛迁移；它不是对本游戏台的效果试验。

下一批的方向

优先探索自由搭建、单维度换规则、遮挡后的主动回忆、按需求取数量及亲子表达场景。空间连接与条件链已有多个代表；新题保持熟悉的操作，只增加一个新要求。具体顺序与难度由兴趣和试玩调整。

年龄用于参考；一次全对不能推出整体发展年龄，离开游戏也不一定是太难。提示后做到、独立做到、换情境做到分开观察。自由创作看是否主动探索和变化，不强行加对错。
