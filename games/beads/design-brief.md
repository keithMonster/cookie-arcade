# 串串珠 · 2026-10-04

目标：新增一款可独立玩的游戏并部署到现有 GitHub Pages。关键假设：Cookie 对出门喽的试玩水位仍适用，喜欢拖放；本轮没有新的能力观察。

## 场景与视觉

- 玩家：2024-07-05 生，当前 26 个月 29 天；不会读字，会拖放和长按。单次约 30 秒到 3 分钟，iPad 触屏为主，同时支持鼠标与键盘。
- medium：web；style_family：既有 Cookie 玩具台（首页及 bus/elevator 大目标、无文字 UI、图形道具）；主代理直接实现单文件 HTML，零运行时依赖。
- keywords：木珠、棉绳、圆方交替、小熊项链；anti：文字答题、计分、自动代答。
- IA：上方接收礼物的小熊，中间六珠绳，底部两种可取珠。首四颗为示范，末两颗是待串道具，不是进度指示。
- user flow：看序列 → 拖珠到下一空位（或点珠再点空位）→ 续接两颗 → 小熊戴项链 → 自动换新一轮。Tab/Enter/Space 与两种指针方式共用 completeStep。

## 准入覆盖矩阵（全部存量按形态归组）

| 交互 | 已有游戏 | 本款差异 |
|---|---|---|
| 拍键/点击即时反馈 | 键盘小子、变色屏、小鼓机、戳泡泡、车车、动物园、Twirlywoos 五款 | 不再新增纯刺激 |
| 点选听说/识别 | 学说话、找一找、送回家、喂一喂 | 答案来自前后关系 |
| 掀开/脚本/擦除/涂画 | 躲猫猫、谁在门后面、洗澡澡、睡觉觉、画彩虹 | 不复制脚本 |
| 拖放/分类/指令 | 装一装、分一分、帮帮忙、排排队 | 续接规律，非数量或分类 |
| 连敲 | 跟着敲 | 第 10 能力线从次数模仿接到 AB 视觉模式 |
| 条件/依赖/空间 | 出门喽、修路喽、电梯叮咚、公交来啦 | 单一交替规则，无额外条件叠加 |

练什么：看出圆方轮流出现的规律，并自己续接。选择拖放因 Cookie 喜欢，点选作为同等入口；旋转和长按对此判断无额外价值。每轮换配色，起始形状和候选左右随机，避免固定位置作答；只用 AB，不叠加 AAB/ABC。

两次错误（含拖偏）只亮正确珠和下一空位；取消手势不计错、不完成，两个空位按顺序处理。语音播放与玩法状态分离，媒体失败不会阻塞。完成定时器独立于音频事件。

## 年龄依据与欠定点

先采用 WHY.md 中 Cookie 的一手反馈，外部资料只是玩法参考。NAEYC 的 [Pattern Books](https://www.naeyc.org/node/1583) 使用可预测重复单位、珠子/项链来开展模式活动；[CDC 30 月](https://www.cdc.gov/act-early/milestones/30-months.html) 给出邻近年龄的一般认知背景，不能据此声称 Cookie 已会模式接龙，也不能把群体里程碑当难度验收。

欠定点：Cookie 实际错误/纠正表现和 iPad 扬声器听感未在此环境取得；默认先发布可回滚的 AB 版本，不宣称孩子已学会。其余目标与上线范围由本轮“新增一个游戏，完成之后直接部署”明确授权；不改旧游戏。

## 验收与回滚

本地浏览器三输入、错序/错珠/取消/多指、跨轮与播放失败；五种视口目标边界与截图；音频 manifest 与离线缓存检查。独立实现审查后 push main，核 Pages build commit 与线上文件哈希。回滚本批新增游戏提交并重发 Pages，不重写历史。
