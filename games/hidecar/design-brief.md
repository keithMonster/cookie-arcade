# 车车藏哪儿

读者是主 Agent 与审查者；已有全台入口与音频构建约定，本文补充本款判断及独立验收范围。2026-10-23，Cookie 为27个月18天。

## 目标与准入

主 Agent 委派的既定目标：三个车库，小车明显驶入随机一个，短暂停留后关门；孩子回忆位置，找到后亲手把车开到路面；重复新轮。发展意义是把刚看见的位置保持到遮挡之后，再主动选择该位置。它补的是短延迟视觉位置记忆，与 peekaboo 的随意掀开、物体恒存脚本有区别；不声称新增完整发展领域，也不把程序通过当作孩子学会。

沿 WHY.md 一手观察：Cookie 拖动利落，长按和双指已有实际能力；旧单步选择有些已全对，出门喽的关系判定会偶错、引导后能改。选用单目标三位置、约半秒关门后的即时选择，不做高速洗牌、计分或关卡。三扇门各保留固定位置和颜色；颜色只是可用的定位线索，没有固定正确颜色。拖车与点车再点路面共用 drive 判定，不把拖动变成记忆任务的额外门槛。

依据复用当前 garden 的27个月邻近发展资料和项目一手观察；具体兴趣、位置记忆水位和耐玩性须 Cookie 实玩。本次不新增外部发展断言。

## 视觉与流程

- medium: web；dispatch: 当前实现 Agent；单 HTML、内联 CSS/SVG、零依赖。
- style_family: cookie-arcade 既有彩色玩具场景，来源 games/garden/index.html。
- scenario_pin: 家庭/旅途反复短玩；30秒至3分钟；不识字但熟悉拖放；手机/iPad横竖屏；离线；完整游戏交付。
- keywords: 三座圆顶卷帘车库、珊瑚红小车、虚线路面、圆太阳、小鸟。
- anti: 文字规则、分数奖励、高速洗牌。
- information_architecture: 左上返回，顶部可互动天空，中间三车库，下部出发路面；小车沿路面到车库的可见路径行驶。
- core_user_flow: arriving 1.3秒 → showing 1.3秒 → closing 0.55秒 → searching → found → leaving 2.65秒 → 新轮。

车明显开入一个车库并短暂显示；三个门一起关闭，之后才可选门。空门打开并轻晃，稍后自行关闭；两次空门后正确门发光，提示始终不替孩子开门。找到后目标门保持打开，车可拖走，也可点车再点路面；两条入口统一调用 drive。路面亮边提示目的地；小车开到路面，短暂停留再驶出画面，随后新轮。不存分数和能力统计。

每个显眼实体都有输入反馈，天空装饰不改变答案。每根指针独立拥有对应实体，同物排他；一指持车，另一指可以开空门、摸装饰或摸路面。目标门在找到后不会关上夹住车。出库咽喉检查 carOwner，持车时另一指不能代为点路面出库；每次新轮释放全部旧指针，跨相位松手只反馈，不操作新相位。pointercancel 仅释放该指针；blur/pagehide/hidden/resize 清全部持有。动画中断重排车位，尚未完成的藏车演示会重播，离开阶段中断开启新轮。语音拒播或缺 ended/error 不影响任何相位。

## 音频 manifest

全部使用同一个 Audio 元素，音量0.3；路径 audio/<key>.mp3。非语音音效本地 Web Audio，增益0.085。

| key | 中文 |
|---|---|
| look | 看，车车开进去了。 |
| find | 车车藏在哪儿？ |
| found | 找到车车啦！ |
| drive | 把车车开到路上吧。 |
| go | 出发喽！ |
| empty | 这里没有，再找找。 |
| hint | 看看亮亮的门。 |

音频构建与共享登记由主 Agent 处理；本实现未调用付费服务。

## 委派验收基线与结果

基线来自主 Agent 开工委派；本文件仅记录子任务范围，浏览器验收由主 Agent 汇总。

- AC-H01：三门单目标、完整可见入库、短延迟后隐藏；错误两次提示不代做；找到并亲自出库后开新轮。源码已落地，浏览器实测未验证。
- AC-H02：点车再点路面与拖车到路面均完整循环；取消拖动不出库。源码已落地，浏览器实测未验证。
- AC-H03：持车时另一指触空门/装饰；两种松手顺序；同车排他；单指cancel、blur/hidden清理。源码已落地，浏览器实测未验证。
- AC-H04：手机/iPad横竖屏大触点、安全区、零文字，无内容裁切。响应式规则已落地，截图实测未验证。
- AC-H05：零外部依赖、单 Audio、不以音频推进相位；只读 window.hidecarDebug。源码检查通过；离线缓存集成与真机扬声器未验证。
- AC-H06：JavaScript语法无错误。node 从 HTML 提取 script 并用 new Function 编译，exit 0，输出 hidecar syntax OK。

关键假设：Cookie愿意看完约3秒的入库遮挡过程；这是可证伪的真实试玩假设。实现层已选固定时长、随机三选一，不需要另增设置。没有未决个人偏好或不可逆参数；全台登记、部署与新增语音构建归主 Agent。
