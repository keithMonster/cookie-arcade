# 小小花园 · 飞行途中可反复照料的口袋花园

读者：实现和审查 Agent 有仓内 HTML 与规则，缺本轮选择依据；读后落实交互和验收。玩家不识字，熟练拖动、长按与双指；界面仅图形和本地语音。

目标原话：在 Cookie 游戏台新增游戏，坐飞机时玩，可以玩的时间长一点；随后授权“完成后直接部署 aa”。主 Agent 理解为可反复探索、可中断续玩且断网完整可用。关键假设：自己选择种植、观察变化和收获，会比固定答案重复更吸引他；真实兴趣需要 Cookie 试玩，不能用自动化证明时长。

## 准入与选择

2026-10-22：27个月17天。先读 WHY 一手观察，保持出门喽的易上手水位。35款矩阵：点选×词义/配对（find/feed）；拖放×分类/数量（sort/basket/picnic）；拖放×关系（bus/bridge/road）；持续操作×修理清洁（garage/bath）；旋转×连通（waterwheel）；开放搭建×结构试验（town）；植物阶段变化×自主照料尚可补。花园拓展开放扮演，不声称新增整个发展领域。

对比固定机场任务（与公交/出门的顺序依赖重复）、再造积木场景（与town重复），选择三块并行花圃：同一个对象经播种、发芽、成熟到收获的可见转换。发展意义：看植物当前状态选下一步，自主安排三块花圃的照料顺序。

参照：[CDC 30个月](https://www.cdc.gov/act-early/milestones/30-months.html)，2026-10-22查原件；假装、简单问题解决、自由选择是邻近依据，不作该孩子的能力评估。真实生长不会如此快，家长图明确这是压缩时间的假装游戏。

## 视觉与操作

medium: web。style_family: cookie-arcade既有彩色玩具场景，复用town/garage的清楚轮廓与克制色彩。场景：飞机座位、手机/iPad横竖屏、随时中断；每次30秒至3分钟完成一次照料，不要求持续盯屏。
keywords: 粗圆木框花圃、种子纸袋、蓝色水壶、带轮收获篮、小狐狸、蜜蜂、阳光。
anti: 文字菜单、等级、金币、倒计时、签到、联网等待。
IA: 左上返回；天空轻反馈；中部三块花圃；下部三种种子和水壶；右侧/下部收获篮及小狐狸餐桌。所有显眼角色和装饰可触碰，反馈不干扰持物。

三种种子：胡萝卜、草莓、花。空地播种→浇水发芽→再次浇水成熟→拖到篮子收获→空地可再种。各花圃独立，不自动整体重开。花色可变化；花篮送到小狐狸桌上，水果/蔬菜不编造动物饮食教学。篮子最多3件，满时提示先点篮子送到桌上，不丢收成。

- 主交互拖种子/成熟作物，水壶拖到花圃停留约600ms浇水，同一手势同一花圃只成长一次，需松手或重新操作；点击工具再点目标保留等价路径，共用判定。错误两次只提示正确工具/目标，不代完成。
- 不允许种子覆盖未收获作物。空地浇水只给水花/播种提示。未熟不能收。篮满不摘除作物。
- 多指按pointerId分工，同一实体排他，释放按最新状态；cancel不提交当前拖放，已真正浇过的水保留。失焦/hidden/resize清掉拖影、持有与计时器。
- 本地只保存已提交三圃状态、篮子与桌上收获，校验版本/类型/种类/范围，坏存档与存储被拒仍能玩。动画和语音均不作为状态提交条件。送篮时立即原子提交收获转移，动画中断不丢物或重复。
- 全部口语本地mp3单Audio，解锁在手势中；语音拒播、结束事件缺失不阻断玩法。持续动画克制，后台停止临时效果，音量≤0.3。
