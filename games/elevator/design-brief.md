# 电梯叮咚 · 设计与验收

## 读者与场景

读者是未来接手这一款的开发 agent：有本仓源码、README 与语音生成器，没有本次试玩对话；需要维护玩法，不把方向判断变成自动代答。

- 玩家：Cookie，2024-07-05 生，本次约 26 个月；不识字，拖放与长按熟练，出门喽 2.0 偶错一两次、语音后能改。月龄不是其能力上限。
- 本轮新观察：Keith 说他很喜欢坐公交、开关电梯门，也看过飞机。只把前两项记为兴趣；不据此推断他已经懂方向。
- 使用频率：家用反复玩，按已有游戏台场景推断；每次约 30 秒至 3 分钟。设备：iPad、手机与桌面；零文字 UI，核心控制至少 56 CSS px。
- 交付：第 28 款独立 HTML 游戏、离线 MP3、首页动态预览、回归脚本、Pages 部署。用户已授权自主选择、完整开发与部署。

## 选择与代价

选择三层电梯送小狐狸去朋友家。公交分岔路线同时引入路线选择和下车，飞机经验较少且容易退化为沿线拖动，留作候选。电梯复用他已会的“先关门才能走”，只新增上下比较和到站判断。

每次上或下一层；相邻与隔一层的目标混合，无关卡、分数、倒计时、自动升级。三位朋友各住一层，同一打开期间住址固定；小狐狸每次从上一次到达的楼层继续，目标始终不同于当前位置。中层朋友可从上方或下方去找，正确方向必须随当前位置改变。目标和整栋楼常驻，不考隐藏目标记忆。

## UI 与交互

视觉锚点：深青舞台、暖黄电梯、三层玩具楼、圆润动物肖像、实体大按钮；拒绝设置面板、数字关卡和全屏奖励遮挡。角色为本页 SVG 插画；返回与方向/开关门控制使用 Lucide 图标形状。

信息结构：顶端“小狐狸想到朋友家”的图像气泡；中间剖面楼，左侧电梯、右侧三位朋友家；底部上下方向与开关门两组按钮。横屏改为楼在左、任务与控制在右；楼的上下关系始终不旋转。气泡、朋友房间可点来重听目标/认识朋友，但不会移动电梯或完成送达。

主流程：看目标 → 关门 → 判断上/下 → 每按一次移动一层 → 到站停稳 → 开门 → 狐狸走到朋友身边，短暂拥抱反馈 → 新目的地。

- 门开着按方向：门轻晃、语音“先把门关好”，位置不变。
- 走错方向：真实走到相邻层，看见离目标更远；语音提醒目标关系。上下边界轻弹，不越界。
- 提前开门：门真的打开，狐狸留在轿厢；提醒还没到，需自己关门后继续。
- 每层停稳响相同的叮声；到正确层也不主动说开门，让孩子自己比较是否与目标朋友对齐。**到站不自动开门、不自动完成**。
- 同一决策连续错两次：下一步正确控制发光；提示只改视觉和语音，不调用操作函数。正确动作后撤掉提示。
- 动画中输入：按钮仍有压下/声音反馈，但不排队、不重复推进。长按不自动重复走层；取消触摸不执行动作。
- 指针按下时记录本轮与可操作性，松开时再核对；移动中按住、停稳后才松开也不执行。松手命中用按压前的位置，避免按钮下沉动画吃掉顶部点击；Space 在按下时处理，按住不跨忙态兑现。
- 语音由单个 Audio 换 src 播放，链带 6 秒看门狗；状态转换仅由独立定时器推进，静音或音频失败都能玩。
- 键盘：上下箭头走一层，左箭头开门、右箭头关门；Tab+Enter/Space 操作按钮，Esc 返回，F 全屏。未映射按键只反馈。
- 无状态持久化、外部网络或第三方运行时；不改其他游戏机制。

## 验收不变量与回退

1. 成功只能发生在本轮、静止、门已打开、当前位置等于目标的位置；到站、错误输入次数、空闲时间、触碰目标画像均不能代替开门。
2. 开门时方向键不能移动；移动时不能开门。每次有效输入只走一层，不存在缓冲输入或长按自动通关。
3. 所有三层起点/终点组合可解；目标相同但起点相反时必须按相反方向。
4. 错站反复开门、反复走错、只点目标、只开关门都不能送达。保留这些负向浏览器检查，并用移除位置守卫的反向样本确认测试会红。
5. 取消、多指、重复键、切后台、换轮回调不跨轮完成；失败音频不堵流程。
6. 320×568、390×844、844×390、768×1024、1024×768 等视口目标完整可见，关键控制至少 56px；听音以真机扬声器为准，桌面验证不冒充真机。
7. README/WHY/STORY/首页/语音 manifest 一致；Pages built SHA 与本地修改文件散列一致，再从线上入口实玩。

回退：revert 本款提交，push main 走现有 Pages 发布；旧款仍以原实现独立运行。

## 研究依据与证据边界

- [CDC 30 月里程碑](https://www.cdc.gov/act-early/milestones/30-months.html)：两步指令、简单问题解决和假装游戏，作为背景；Cookie 的直接观察优先。
- [CDC 的用途说明](https://www.cdc.gov/act-early/milestones/key-points.html)：里程碑不是儿童发展的标准，不拿清单给游戏设能力上限。
- [Harvard 18–36 月活动指南](https://developingchild.harvard.edu/wp-content/uploads/2024/10/Executive-Function-Activities-for-18-to-36-month-olds.pdf)：围绕目标行动、尝试后调整、用语言描述动作和帮助反思；这里借鉴活动原则，不宣称本款屏幕游戏提高智商或脑发育效果已获验证。
- [Apple 无障碍设计](https://developer.apple.com/design/human-interface-guidelines/accessibility)：触摸目标与视觉/声音并行反馈；本款按幼儿手指进一步放大控制。

试玩判断沿用既有水位：偶错、提示后能改、还想玩则合适；一次全对多轮不变则再考虑增加结构；频繁乱按且不理解时先降低提示理解负担。开发测试只验机制，不替代 Cookie 的兴趣和难度反馈。
